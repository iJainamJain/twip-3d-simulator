# TWIP-3D Self-Balancing Robot Simulator

A browser-based 3D digital twin of a two-wheeled self-balancing robot (ESP32 + MPU6050 + TB6612FNG + HC-SR04).

**Play it here: https://ijainamjain.github.io/twip-3d-simulator/**

- Live physics with a cascaded PID controller and Kalman-filtered IMU
- Push/pull stress tests, sonar autonomy, sumo and convoy modes, PID tuning
- A landscape of hills, mountains, boulders, walls, ice and mud
- **Summit Run** game: drive from the start chute through 4 checkpoints to the summit flag

Controls: WASD / arrow keys or the on-screen stick, `[` `]` toggle panels, `1`-`6` switch sections.

Works offline too: download this repository and open `index.html`.
